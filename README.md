# Demand Signal Repository & Forecasting Engine

A GenAI-powered demand signal repository and forecasting system to unify sales, inventory, and external signals into actionable procurement intelligence.

## Features

- **Data Ingestion Pipeline**: Ingests and validates synthetic multi-source demand data.
- **Forecasting & Inventory Health Engine**: Predicts demand trends and classifies inventory risk (Understock, Overstock, Healthy).
- **GenAI Copilot**: LangChain/LangGraph agent for natural language analytics and explainable insights.
- **Streamlit Dashboard**: Multi-page UI mapping supply chain wireframes.

## Quickstart Guide

1. **Install Dependencies:**
